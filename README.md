# Olympic Meridian

Платформа подготовки к олимпиадам по географии: учебные группы, материалы, практика, пробные олимпиады и проверка работ. Интерфейс на русском и казахском языках.

Next.js 15 · React 19 · TypeScript · Tailwind CSS · Prisma 6 · PostgreSQL/Neon · Cloudflare R2.

## Запуск существующего проекта

1. Установить Node.js 24 и зависимости: `npm ci`.
2. Скопировать `.env.example` в `.env\_\_ и настроить соединение с базой, AUTH_SECRET, почтовый сервис и R2.
3. Сгенерировать клиент: `npx prisma generate`.
4. Для новой базы применить миграции: `npx prisma migrate deploy`. Перед изменениями существующей рабочей базы сделать её резервную копию.
5. Запустить `npm run dev` и открыть http://localhost:3000.

Регистрация требует доставки кода подтверждения: настройте Brevo или Resend. В режиме разработки при отсутствии почтового провайдера код выводится только в локальный журнал сервера. Загрузка файлов требует настроенного R2.

`npm run prisma:seed` предназначен только для локальной демобазы. Скрипт больше не очищает таблицы и не допускает запуск на удалённой базе. Если демо-аккаунты уже существуют, данные сохраняются.

## Безопасная локальная проверка

Можно проверять сайт без доступа к рабочим данным:

1. Запустить отдельную базу:
   `npx prisma dev --name geoolymp-qa --port 51223 --db-port 51224 --shadow-db-port 51225`.
2. В локальном `.env__ задать DATABASE_URL и DIRECT_URL со стандартным PostgreSQL-адресом этой базы на localhost:51224. Для Prisma dev добавить параметры `pgbouncer=true&connection_limit=1&statement_cache_size=0`.
3. Выполнить `npx prisma db push`, затем `npm run qa:seed`. Этот скрипт разрешён только для localhost:51224.
4. Запустить `npm run dev`.

Тестовые входы: `teacher@example.test` и `student@example.test`, пароль `geoolymp-qa-2026`. Это локальные учебные аккаунты; на рабочий сайт их переносить не нужно.

## Проверки

- `npm test` — статусы, подсчёт баллов, координаты карты и нормализация черновиков.
- `npm run typecheck` — TypeScript.
- `npm run test:integration` — HTTP-сценарии учителя и ученика. Нужны запущенный локальный сайт и отдельная база на localhost:51224. Тест создаёт только собственные учебные записи.
- `npm run build` — генерация Prisma Client и production-сборка.
- GitHub Actions повторяет проверки, включая HTTP-сценарии на PostgreSQL 16.

PostCSS и deepmerge-ts закреплены через overrides на исправленных совместимых версиях. При изменении зависимостей повторите генерацию Prisma, тесты, сборку и `npm audit`. На Windows генерация Prisma требует остановить сервер, использующий его DLL.

## Работа с задачами

- В кабинете ученика сначала показаны текущее занятие, новые результаты и группы.
- Обычная практика допускает повторные ответы. Черновики сохраняются на устройстве отдельно для каждого пользователя и задачи; файлы черновика браузер не сохраняет.
- В пробной олимпиаде ответы автоматически сохраняются на сервере. Перед завершением незавершённые запросы сохраняются; при ошибке сети завершение приостанавливается. Дедлайн и единственную попытку контролирует сервер.
- Начатая олимпиада фиксирует состав и условия задач. Для новой версии создайте другую подборку.
- Учитель создаёт задачу прямо в подборке, добавляет существующие задачи несколькими и меняет порядок. Условие, варианты и разбор доступны в одной форме.
- Полностью решённой считается задача с максимальным баллом. Частичный балл, неверный ответ и ожидание проверки показываются отдельно.

## Публикация и возврат

Рабочая версия развёрнута на Vercel. Используйте `npm run build` как команду сборки. Для этих доработок схема базы не менялась и новые миграции не требуются.

Исходная версия сохранена в ветке `backup/before-redesign-2026-11-05` и метке `backup-before-redesign-2026-11-05` (коммит `ed530dad23b184379b499d5d20aa57b3e688bf68`). Для возврата кода повторно разверните этот коммит либо соответствующий прежний deployment Vercel. База данных, загруженные файлы и настройки окружения сохраняются отдельно от Git.
